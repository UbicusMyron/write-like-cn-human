# 中文表达示例

这些例子说明如何判断句子用途和中文搭配。具体写作时沿用真实材料中的主体、事实与条件。

## 防御发言与有效条件

原句：
> 我建议先做用户访谈。这并不意味着用户访谈能够解决所有问题，也不能保证最终的产品一定成功。

改写：
> 我建议先做用户访谈，了解用户目前如何处理这项工作，以及他们在哪些环节遇到困难。

上下文：访谈目的已经明确为了解用户现有工作方式。后面两个否定没有帮助用户开展访谈。

需要保留的条件：
> 这次访谈只覆盖现有付费客户。制定新用户方案前，需要补充新用户访谈。

这里的样本范围影响下一步行动，应当保留。

## 正向表达与软件边界

原句：
> 这个 skill 不是为了炫技，也不是为了让文字看起来高深，而是帮助用户理解内容。

改写：
> 这个 skill 帮助用户理解内容。

有实际意义的否定：
> 接口不接受空字符串；调用方应当提供至少一个字符。

空字符串是明确的输入边界，否定提供了必要信息。

## 补全动作及其对象

原句：
> 对齐之后，把工作给出去，再做闭环。

改写：
> 你和 agent 确认任务要求后，把资料整理工作交给 agent，最后检查整理结果是否符合要求。

上下文：任务是资料整理，参与者是用户和 agent，检查标准是已确认的任务要求。这些信息已经给出，改写将其放回句子。

原句：
> 通过能力建设实现效能提升。

处理方式：
> 先确定谁需要提高什么能力，以及希望改善哪项工作，再据此改写。

原句没有提供足够信息，无法凭空补出培训项目、执行者或效果数据。

## 双音节词与自然搭配

| 原表达 | 更适合当前偏好的表达 | 判断依据 |
|---|---|---|
| 改方案，查结果 | 修改方案，检查结果 | 完整动词读起来更自然 |
| 把工作给出去 | 把工作交给 agent | 动作和接收者明确 |
| 企业正在转型 | 企业正在进行业务转型 | 已知对象是业务，完整词组更易理解 |
| 先分析需求 | 先开展需求分析 | 适合正式方案中的工作安排 |
| 我吃苹果 | 我吃苹果 | 单音节动词与宾语搭配自然 |
| 用户写文章 | 用户写文章 | 动作明确，表达自然 |

“开展需求分析”和“分析需求”都可以成立。根据句子节奏和场景选择，优先照顾用户对完整中文表达的偏好。

## 结论先行与有效论证

原句：
> 考虑到任务会重复出现，而且处理步骤相对固定，同时你希望减少每次重新说明的时间，综合来看，我们可以考虑把它做成 skill。这样做能够复用这些要求，也就是说，以后可以继续使用同样的要求。

改写：
> 建议把这项任务做成 skill。任务会重复出现，处理步骤也相对固定，保存这些要求可以减少每次重新说明的时间。

推荐意见在开头，后面提供支持该意见的依据，信息表达完整后结束。
